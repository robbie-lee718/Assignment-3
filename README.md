# Meteor Rush — Assignment 3

Arcade shooter game built in Unity. Created a complete 2D shooter with player movement, shooting, enemies, meteors, health, score, and game over logic.

---

## Features Built

- Player ship movement
- Player shooting system
- Enemy ship behavior
- Enemy shooting system
- Meteor hazards
- Projectile collisions
- Health system
- Score system
- Sound effects
- Game over and restart logic
- Complete arcade gameplay loop

---

## Controls

| Action | Key |
|---|---|
| Move Left | A / Left Arrow |
| Move Right | D / Right Arrow |
| Shoot | Left Mouse Button |

---

## Folder Structure

| Folder | Purpose |
|---|---|
| Audio | Sound effects used throughout the game |
| Prefabs | Reusable game objects |
| Scenes | Unity scenes |
| Scripts | Gameplay scripts |
| Sprites | Player, enemy, missile, meteor, and background sprites |
